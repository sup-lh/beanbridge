# 豆桥可以长成什么

以下是产品设想，不是现有能力清单。

## 随身语音工作台的演进状态

从单一按键发送助手向语音工作台拓展的过程中，当前工程已进入系统级模块演进。以下是核心能力的当前状态纪实：

| 模块 | 核心能力与设计 | 当前状态与验证范围 |
|---|---|---|
| **本地高精度模型、下载中心与热词表** (`ASRModelCatalog` / `ASRService` / `ASRModelManagerWindow`) | 采用 whisper.cpp 本地转写；应用内提供 Hugging Face 官方源与 `hf-mirror.com` 镜像源下载管理，实时显示百分比、速度与剩余时间，支持关闭弹窗后台续传、分块 SHA-256 校验、模型增删改选及 `support/hotwords.txt` 专词提示。 | **本机下载与离线单测验证**：已实机在桌面端下载、校验并切换 `ggml-small.bin`（465 MB），通过 6 项离线单测与 `jfk.wav --self-test` 自检；大模型实时预览延迟与长时间发热待更多长录压测。 |
| **无 ffmpeg 预览下采样优化** (`LivePreview`) | 为降低实时流预览的延迟与系统依赖，剥离外部 ffmpeg 进程，在 Swift 内存中直接对 PCM/Opus 音频流进行纯内存无依赖 48kHz -> 16kHz 重采样与轻量化下采样。 | **代码级验证**：已避免外部进程卡死或环境缺失问题，预览延迟大幅降低，编译自检全绿。 |
| **BLE 自动重连与睡眠恢复** (`ReconnectCoordinator`) | 指数退避重连算法（初始 1s、最大 30s、1.5x 递增，带抖动防止风暴）；监听 NSWorkspace 系统休眠与唤醒通知；在休眠前执行 `prepareForSleep` 取消挂起等待并干净断开，唤醒后重置状态并自动拉起重连。 | **单元测试通过**：逻辑与生命周期状态机已实现，通过包含 `.sleeping` 断线保护等 16 项自动化回归测试；**严禁误写为真机实测通过**（尚未在 D3200 真实硬件全天休眠场景中进行稳定性跑测）。 |
| **离机增量同步** (`WorkbenchSync`) | `SyncManifestStore` 原子记录已同步文件 ID 清单（文件权限 `0o600`，目录 `0o700`）；设备连上后自动读取离机录音列表，仅拉取未同步新增片段；支持进度报告与断点续传。 | **模块逻辑与测试验证**：清单持久化与过滤逻辑已通过代码校验；**尚未在真实硬件长离线积压音频场景完成实测**。 |
| **VAD 切片与灵感收集箱** (`WorkbenchPanel`) | 对大段或长语音进行本地语音活动检测（VAD）自动切片，形成带起止时间戳的片段；灵感收集箱提供分段检索、快速试听回放，并支持一键将某段灵感转发给目标会话；结合 `NSStatusItem` 菜单栏常驻与取消本条录音控制。 | **本地编译与回归自检通过**：VAD 切片计算、起止时间戳检索、面板组件与数据模型均已实现并通过自动化测试；真实按键全天使用待后续实机跑测。 |

| 场景 | 你怎么使用 | 产品产出 | 优先级 |
|---|---|---|---|
| 口述编程 | 对着页面说明要改哪里 | 一条有明确目标的 Codex 消息 | 首先完善 |
| 灵感收集 | 走动时按键记一段想法 | 带时间的想法条目，回来后选一条继续做 | 下一阶段 |
| 工作回放 | 问“刚才决定了什么” | 相关原话、时间点和上下文 | 需要索引与检索 |
| 任务草稿 | 口述“明天记得……” | 一张待办草稿，由用户决定保存到哪里 | 需要目标应用集成 |
| 项目记忆 | 一周内反复谈同一件事 | 项目决策时间线、未决问题 | 需要来源和更新机制 |

“你说完，事情有了去处”比积累很多录音更容易形成日常使用习惯。先把按键启动速度、目标可见性、识别质量和失败恢复做扎实。

## 全天录音为什么不应每次重读

全天录音的处理量取决于实际发声时长、识别模型、机器性能和要回答的问题。不能把“录了八小时”等同于“模型要看八小时”，也不能在未测量前承诺几秒完成。

可以逐段处理：音频切片 → 发声检测 → 本地/所选服务转写 → 保留时间戳 → 形成小段摘要 → 建立检索索引。查询时先找相关片段，再取原文和必要音频。日报基于已处理片段汇总，只有新内容需要继续计算。

全天录音还需要明确的开始/暂停状态、容量和电量管理、片段保留周期、其他在场者知情，以及按段删除和导出能力。当前版本没有这些能力，因此不应当作全天候记忆设备使用。

## 建议的迭代顺序

1. **输入可靠**：实体按键、本地预览、取消本条、目标可见、失败待发箱。
2. **去向清楚**：菜单栏选择对话、指定工作目录新建、确认一次后记住偏好。
3. **记录可找回**：灵感盒子、时间线、搜索和原文跳转。
4. **行动可追踪**：把选中的片段交给 Codex 或任务系统，显示是否完成。

首个产品指标可以很具体：用户在不碰键盘的情况下，成功把一条意思完整的需求发到正确对话；失败时能知道发生了什么，原话还能找回来。
